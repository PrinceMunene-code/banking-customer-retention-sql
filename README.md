# Banking Customer Retention Analysis (SQL Server)

## Problem
Retail banks need to identify inactive customers early and understand which segments contribute most to churn.

## Dataset
Simulated banking data including customers, accounts, transactions, and balances.

## Approach
- Designed a normalized relational schema
- Defined churn behaviorally as 90-day transaction inactivity
- Analyzed churn by age group and region
- Built executive-level KPI queries using T-SQL

## Key Insights
- Churn is not evenly distributed across customer segments
- Younger customers show higher inactivity rates
- Certain regions exhibit higher churn risk

## Tools
- SQL Server (SSMS)
- T-SQL
